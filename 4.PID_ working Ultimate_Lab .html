3Pole-Zero Map

Closed-loop poles in s-plane — left = stable, right = unstable
🎯 HOW TO READ THE POLE MAP

Real part (σ) = decay rate. More negative σ = faster decay = more stable. If σ > 0, system BLOWS UP.
Imaginary part (jω) = oscillation frequency. Larger = more ringing in response.
Damping ratio ζ = cos(angle from −σ axis). ζ=0.7 → ~4% overshoot. ζ<1 = underdamped. ζ=0 = oscillating forever.
Distance from origin = natural frequency ωₙ. Farther = faster overall system response.

4Bode Plot — Frequency Domain View

Gain and phase vs frequency — stability margins at a glance
📡 READING THE BODE PLOT

Gain Crossover (0 dB line): Your bandwidth — frequencies the controller actively controls. Higher = faster.
Phase Margin (PM): PM > 45° = robust. PM < 30° = fragile. PM < 0° = UNSTABLE.
Kd effect: Adds phase LEAD (the bump in orange curve). This physically gives the controller a "head start" — that's why derivative action improves stability margins!

🌍 FROM PHYSICS TO TRANSFER FUNCTION

Every real system has physical components that create the transfer function. The same PID mathematics applies to all — only the physical meaning of parameters changes. Understanding WHY the transfer function looks the way it does separates a researcher from a technician.

🚗 CAR CRUISE CONTROL

Engine → Wheels → Speed
G(s) = 1/(ms + b)
m=mass(kg), b=aerodynamic drag

Physical Story: Throttle = force F. Car has inertia m. Wind/road drag b resists. Newton: m·dv/dt = F − b·v. Laplace → G(s) = 1/(ms+b).

PID Role: Kp = "press harder if speed error large". Ki = "keep pressing even on hills (constant disturbance)". Kd = "ease off before reaching target (anti-overshoot)".

Key Insight: Without Ki, car never reaches exact speed on an incline. The hill is a constant disturbance — only integral eliminates it permanently.

⚙️ DC MOTOR SPEED

Voltage → Current → Torque → RPM
G(s) = Km / [(Ls+R)(Js+b)]
L=inductance, R=resistance, J=inertia, b=friction

Physical Story: Apply voltage V → current flows through R+L → magnetic torque → spins rotor against inertia J and friction b. Two time constants: electrical τₑ=L/R (fast, ms), mechanical τₘ=J/b (slow, s).

Key Insight: High Kd + electrical noise = derivative kick → dangerous current spikes. Real motor controllers use derivative-on-measurement, not derivative-on-error. Also uses anti-windup on Ki!

🚁 DRONE ALTITUDE HOLD

Thrust → Net Force → Accel → Height
G(s) = 1/(ms²) — Double Integrator!
m=total mass, inherently unstable plant

Physical Story: Thrust T − mg = ma. Position = ∬ acceleration. This creates 1/ms² — a double integrator. Already marginally stable at best.

Key Insight: Adding Ki to a double integrator adds THIRD pole at origin = extremely unstable. Drone altitude loops often use PD only, not PID! Modern drones use cascaded control: outer (position, slow PD) + inner (attitude, fast PID).

🚀 ROCKET THRUST VECTOR

Gimbal Angle → Thrust Direction → Attitude
G(s) ≈ 1/(Is²) · e^(-τs)
I=moment of inertia, τ=actuator delay

Physical Story: Rocket nozzle gimbal tilts → off-axis thrust → torque rotates rocket. Attitude = double integral of angular acceleration. Dead time τ from hydraulic actuator lag.

Key Insight: Falcon 9 uses triple-redundant PID loops with adaptive gain scheduling — gains change based on fuel burn (mass changes during flight!). Extremely tight bandwidth required: delay + double integrator kills stability margins.

1Newton's Law → Transfer Function

📐 COMPLETE DERIVATION — CAR SUSPENSION

Car wheel (mass m) on spring (k) with damper (b):

Newton's 2nd Law: m·ÿ + b·ẏ + k·y = F(t)

Laplace Transform (zero initial conditions):
ms²Y(s) + bsY(s) + kY(s) = F(s)

Transfer Function: G(s) = Y(s)/F(s) = 1/(ms² + bs + k)

With m=1, b=10, k=20: G(s) = 1/(s² + 10s + 20)

Natural frequency: ωₙ = √(k/m) = √20 ≈ 4.47 rad/s
Damping ratio: ζ = b/(2√(km)) = 10/(2×√20) ≈ 1.118 (overdamped → no overshoot without control!)

3Routh-Hurwitz Stability Criterion

📊 EXACT STABILITY BOUNDARIES FOR PID + 2ND ORDER PLANT

Closed-loop characteristic polynomial with PID on G(s)=k/(ms²+bs+k):

Δ(s) = (m+Kd)s³ + (b+Kp)s² + (k+Ki)s + 0 → wait, with integral:
Δ(s) = m·Kd·s³ + (m+b·Kd+Kp·m)s² + ... (full Routh array applied)

Simplified for unit plant 1/(s²+10s+20) with PID:
Closed-loop: T(s) = [Kd·s² + Kp·s + Ki] / [(1+Kd)s³ + (10+Kp)s² + (20+Ki)s + Ki·something]

Routh Stability Condition → Row 3 must be positive:
(10+Kp)(20+Ki) − Ki·(1+Kd) / (10+Kp) > 0

Result: Ki < (10+Kp)·20 / (1+Kd − (10+Kp)) for stability.
This is the EXACT mathematical reason why high Ki causes oscillations!

4Ziegler-Nichols Method

🔑 THE ENGINEERING SHORTCUT — FIND ULTIMATE GAIN

Step 1: Set Ki=0, Kd=0. Increase Kp until sustained sinusoidal oscillation begins.
Step 2: Record K_u (ultimate gain) and P_u (oscillation period in seconds).
Step 3 — Apply ZN formulas:
→ Kp = 0.6 × K_u
→ Ti = P_u / 2 → Ki = Kp/Ti = 1.2·K_u/P_u
→ Td = P_u / 8 → Kd = Kp·Td = 0.075·K_u·P_u

Why it works: At K_u, closed-loop poles sit exactly ON the jω axis (marginally stable). ZN places them deliberately at ~60% of the stability limit — giving a phase margin of ~30–45°, accepting some overshoot (~25%) for speed.

5Bode Plot & Frequency Domain

📡 READING STABILITY MARGINS

Gain Margin (GM): How much gain can increase before instability. Read at phase = −180°. GM > 6 dB = safe, robust design.
Phase Margin (PM): How much more phase lag before instability. Read at |G|=0 dB. PM > 45° = robust. PM=0° = sustained oscillation. PM<0 = already unstable!
Derivative action adds phase lead: That is the positive bump in the orange phase curve at high frequencies. The "lead" gives the controller information about the FUTURE, improving PM by 30–60°!

💻 COMPLETE MATLAB CODE — ANNOTATED RESEARCH LEVEL

Every intermediate signal is traced and explained. This is how a researcher debugs a PID system — not just looking at final output, but inspecting every node of the block diagram.

1Plant + Transfer Function

%% ================================================================ %% STEP 1: DEFINE PHYSICAL SYSTEM — Car Suspension %% Physics: m·ÿ + b·ẏ + k·y = F(t) → Laplace → G(s) = 1/(ms²+bs+k) %% ================================================================ m = 1; b = 10; k = 20; %% INTERMEDIATE 1: Natural frequency & damping wn = sqrt(k/m); % = 4.47 rad/s zeta = b/(2*sqrt(k*m)); % = 1.118 (overdamped!) fprintf('wn=%.3f rad/s, zeta=%.3f\n', wn, zeta); %% >> wn=4.472 rad/s, zeta=1.118 ← slightly overdamped! plant = tf([1], [m, b, k]); % G(s) = 1/(s²+10s+20) %% INTERMEDIATE 2: DC gain (steady-state without controller) dc = dcgain(plant); % = 1/20 = 0.05 ← only 5% of target! fprintf('Plant DC gain = %.4f (reaches %.1f%%)\n', dc, dc*100); %% >> Plant DC gain = 0.0500 → WHY we need integral action!

2PID Controller Design

%% ================================================================ %% STEP 2: BUILD ALL THREE CONTROLLERS %% ================================================================ Kp = 5; Ki = 10; Kd = 1; P_ctrl = pid(Kp); % C(s) = 5 PI_ctrl = pid(Kp, Ki); % C(s) = 5 + 10/s PID_ctrl = pid(Kp, Ki, Kd); % C(s) = 5 + 10/s + s %% CLOSED-LOOP: T(s) = C(s)·G(s) / [1 + C(s)·G(s)] sys_P = feedback(P_ctrl*plant, 1); sys_PI = feedback(PI_ctrl*plant, 1); sys_PID = feedback(PID_ctrl*plant, 1); %% INTERMEDIATE 3: Verify DC gains (= 1.0 if integral present) fprintf('DC gains: P=%.3f PI=%.3f PID=%.3f\n', ... dcgain(sys_P), dcgain(sys_PI), dcgain(sys_PID)); %% >> DC gains: P=0.200 PI=1.000 PID=1.000 %% P only reaches 20% of target! PI/PID reach exactly 100%

3Compute Performance Metrics

%% ================================================================ %% STEP 3: EXTRACT ALL PERFORMANCE METRICS %% ================================================================ t = 0:0.001:5; %% INTERMEDIATE 4: Step responses y_P = step(sys_P, t); y_PI = step(sys_PI, t); y_PID = step(sys_PID, t); %% INTERMEDIATE 5: Rise time (10%→90% of final value) info_P = stepinfo(sys_P); info_PID = stepinfo(sys_PID); fprintf('P: Rise=%.3fs Overshoot=%.1f%% Settle=%.3fs\n', ... info_P.RiseTime, info_P.Overshoot, info_P.SettlingTime); fprintf('PID: Rise=%.3fs Overshoot=%.1f%% Settle=%.3fs\n', ... info_PID.RiseTime, info_PID.Overshoot, info_PID.SettlingTime); %% >> P: Rise=0.124s Overshoot=0.0% Settle=0.412s (slow, no overshoot, 80% error!) %% >> PID: Rise=0.087s Overshoot=9.3% Settle=0.673s (fast, some overshoot, zero error)

4Trace Individual PID Signals

(see full RK4 in simulator JS) prev_err = e; end %% KEY INSIGHT: At t=0, D term is HUGE (large de/dt → burst) %% At t→∞: P and D → 0 (error→0), only I maintains steady effort %% The I term is what "remembers" the needed DC bias
